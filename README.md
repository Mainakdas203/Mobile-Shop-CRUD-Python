# Mobile-Shop-CRUD-Python

A simple console-based Mobile Shop Management System developed using Python.

## Features

- Add Mobile
- Display All Mobiles
- Search Mobile
- Update Mobile
- Delete Mobile
- Exit

## Technologies Used

- Python
- Functions
- Lists
- Loops
- Conditional Statements
- Match-Case

## Data Structure

Each mobile is stored in a Python list:

[id, brand, model, price, quantity]

Example:

[101, "Samsung", "Galaxy A55", 35000, 5]

## CRUD Operations

| Operation | Function |
|---|---|
| Create | add_mobile() |
| Read | display_mobiles() |
| Search | search_mobile() |
| Update | update_mobile() |
| Delete | delete_mobile() |

## How to Run

```bash
python mobile_shop_crud.py
